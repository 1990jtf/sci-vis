# 科普可视化（面向儿童科普）

面向儿童的科学知识可视化项目。基于 Three.js 的极致 3D 交互演示：电影级色调映射（ACES）+ UnrealBloom 泛光后处理、程序化生成贴图、平滑运镜、流光 Shader、统一玻璃拟态设计系统。帮助孩子通过直观、有趣的 3D 动画认识科学。

**在线访问：<https://1990jtf.github.io/sci-vis/>**（由 GitHub Actions 自动部署，推送 main 即更新）

## 架构说明

- **shared/theme.css**：统一设计系统——深空玻璃面板、控制坞、图例、信息卡片、加载层、CSS2D 标签，全站一套视觉语言。
- **shared/kit.js**：共用运行时（ES Module）：渲染器（ACES + UnrealBloom）、平滑运镜 makeFly、拾取 makePicker、语音、信息卡片、程序化纹理 planetTexture（fbm 噪声）、星空等。页面通过 SciVis.init(THREE, {OrbitControls, EffectComposer, RenderPass, UnrealBloomPass}) 注入依赖。
- **单文件交付**：为保证 file:// 双击可用，页面内的 kit 已内联。修改 kit.js 后运行 `node tools/inline-kit.js` 重新内联。

## 语音讲解方案

浏览器自带的 `speechSynthesis` 只能调用操作系统音色（macOS 上的 "Tingting" 等），机械感强、断句生硬。项目因此做了两级方案，`S.createVoice({ audioBase })` 自动选择：

1. **神经语音包（首选）**：用微软 Edge 神经网络音色（`zh-CN-XiaoxiaoNeural`，温柔女声）离线预生成 mp3，放在 `src/audio/<页面>/v_<id>.mp3`。真人感强、无需 API Key、断网也能播；缺失时自动降级。
2. **浏览器语音（兜底）**：按"云端自然音 > 增强音色 > 本地音色"打分挑最优中文音色，并把长句按标点切成短句依次朗读（句间 90ms 停顿），比直接取第一个中文音色自然得多。

重新生成某页的语音包（改了 `say` 文案后要跑一次）：

```bash
pip install edge-tts
node tools/gen-voice.js src/solar-system/solar-system.html
# 换音色 / 语速：
VOICE=zh-CN-YunxiNeural RATE=-2% node tools/gen-voice.js src/solar-system/solar-system.html
```

脚本会读取页面里 `/* @voice-data-begin */ … /* @voice-data-end */` 之间的数据块，把里头的顶层数组 / 对象映射摊平，逐条取带 `id` 与 `say` 的条目合成，文案没变就跳过；`index.json` 记录每条文案的哈希。已接入语音包的页面：

| 页面 | 音频目录 | 条数 |
| --- | --- | --- |
| 太阳系 | `src/audio/solar-system/` | 19 |
| 恐龙 | `src/audio/dinosaur/` | 12 |
| 血液循环 | `src/audio/circulation/` | 21 |
| 水循环 | `src/audio/weather/` | 17 |
| 江南园林 | `src/audio/garden/` | 16 |
| 悬泉置 | `src/audio/xuanquan/` | 10 |

其他页面想接入，只需给数据块加这两个标记、给实体加 `id` 与 `say`，再 `S.createVoice({ audioBase: '../audio/<页面>/' })` + `voice.speak(data.say, data.id)`。

可选音色：`zh-CN-XiaoxiaoNeural`（女·温柔）、`zh-CN-XiaoyiNeural`（女·童趣）、`zh-CN-YunxiNeural`（男·活泼）、`zh-CN-YunjianNeural`（男·浑厚）。

## 科普列表


### 🪐 太阳系 · 地球自转与公转（src/solar-system/solar-system.html）

基于 Three.js 制作的交互式太阳系 3D 演示，包含太阳、八大行星（水星、金星、地球、火星、木星、土星、天王星、海王星）与 9 颗卫星（月球 + 火卫一/二、木卫一/二/三/四、土卫六、天卫三、海卫一）。

**核心功能：**

- **行星自转与公转**：每颗行星按相对真实的速度绕太阳公转并自转，保留自转轴倾角；卡片里给出真实的自转周期与公转周期
- **卫星系统**：月球绕地球公转，自转与公转同步（潮汐锁定，永远是同一面朝我们）；火星、木星、土星、天王星、海王星各带代表卫星，可点击查看
- **距离三件套**：每个天体同时给出「距太阳（公里）」「折合光年」「光行时」——例如地球 1.50 亿 km / 1.58×10⁻⁵ 光年 / 8 分 19 秒，帮孩子建立"光也要跑很久"的尺度感
- **交互查看**：点击任意天体或标签，弹出介绍卡片（自转周期、公转周期、直径、卫星数、温度等）
- **语音讲解**：神经语音（晓晓）真人感讲解，选中天体即朗读（可开关）
- **自动漫游**：一键自动漫游，镜头依次飞向各天体并语音介绍（含月球）
- **轨道可视化**：半透明圆环展示行星与卫星的轨道
- **自由视角**：鼠标拖拽旋转视角，滚轮缩放（OrbitControls），选中后镜头上跟随天体
- **土星环**：为土星绘制了标志性的环

**操作方式：**

| 操作 | 说明 |
| ---- | ---- |
| 点击天体 / 名称标签 | 查看科普介绍卡片 |
| 拖拽 | 旋转视角 |
| 滚轮 | 缩放 |
| 🔊 按钮 | 开启/关闭语音 |
| ⏸ 按钮 | 暂停/继续动画 |
| 🚀 自动漫游 | 开启/停止自动漫游 |

**技术要点：**

- 使用 Three.js 0.160（通过 importmap 从 CDN 加载，无需本地构建）
- 自包含单文件页面，可直接 `file://` 打开
- `OrbitControls` 实现轨道相机控制
- `CSS2DRenderer` 实现天体名称标签（标签可点击，点小卫星更省事）
- `Raycaster` 实现点击拾取
- `S.createVoice({ audioBase })` 播放预生成的神经语音，缺失时降级到 `speechSynthesis`
- 光年 / 光行时由公里数实时换算（1 光年 = 9.4607 万亿 km，光速 299792.458 km/s），数据只有一份来源
- 2000 颗随机分布的点作为星空背景

> 说明：轨道速度按真实周期比例压缩显示（否则海王星一年要等 164 年），但卡片里的周期、直径、距离都是真实值。

## 科普列表

### ❤️ 人体 · 血液循环（src/circulation/circulation.html）

程序化生成的解剖人体 + 11 个内脏 + 22 段血管，展示体循环与肺循环。

**核心功能：**

- **五层解剖模型，可以逐层剥离**（参考 Complete Anatomy 的思路）：皮肤 / 肌肉 / 骨骼 / 内脏 / 血管 各占一层，右侧「解剖图层」面板可任意组合开关。皮肤不是整体半透明，而是**不透明皮肤 + 胸腹正面开一个解剖窗**——这才能同时有皮肤质感和内部结构，整体半透明只会像塑料人偶
- **皮肤用自定义 shader**：菲涅尔边缘让轮廓厚实、正面透出皮下血色，叠加一层细血管纹理；头部单独走半透明通道，能看见颅骨包着大脑
- **骨骼层**：12 对肋骨（1~7 肋连胸骨、8~10 肋汇成肋弓、11~12 浮肋）、胸骨、双侧锁骨、24 节带棘突的脊柱（颈曲前凸、胸曲后凸、腰曲前凸）、骨盆（髂骨翼 + 坐耻骨环 + 骶骨）、颅骨与下颌、四肢长骨（肱骨/尺桡骨/股骨/胫腓骨，关节处带骨端）
- **肌肉层**：胸大肌（4 束纤维合成一片，止于肱骨）、腹直肌 4 对肌腹、腹外斜肌、斜方肌、三角肌、肱二头肌/三头肌、股四头肌、腘绳肌、小腿三头肌、胫骨前肌
- **11 个内脏，逐个按解剖轮廓建模**：心脏（心室放样 + 右心室鼓包 + 双心房 + 冠状沟 + 冠状动脉 + 升主动脉/肺动脉干根部）、左右肺（一整片曲面，叶裂处内凹 + 气管支气管树）、大脑（脑回褶皱 + 纵裂 + 颞叶 + 小脑 + 脑干）、肝（右叶主体 + 左叶薄舌 + 肝门 + 胆囊）、胃（贲门—胃底穹顶—胃体—幽门 + 食管 + 十二指肠）、小肠（6 列纵向悬挂的肠袢 + 环状襞）、大肠（盲肠→升→横→降→乙状→直肠 + 阑尾 + 结肠袋）、双肾（豆形 + 肾门 + 输尿管）、脾、胰（头体尾渐变）、膀胱
- **每个器官 3~5 条数据 + 2 条描述 + 2 条「冷知识」**：例如肝脏"功能 500 多种""切掉 70% 仍能长回来"，小肠"吸收面积约 200 平方米""只有 2.5 厘米粗却拉直有六七米"
- **22 段血管按骨骼地标走向**：主动脉（带主动脉弓）、颈动脉、上下肢动静脉成对、肝/肾/肠系膜分支、上下腔静脉、门静脉、肺动脉干与左右分支、肺静脉——不再是装饰性的发光管子
- **循环分层**：全部 / 体循环 / 肺循环 一键切换，切到肺循环时肺会变成"玻璃肺"，肺内血管直接透出来，并配一段对应的路线讲解
- **血液粒子**：约 900 个实例化粒子沿每条血管的真实路径流动，选中某个循环时自动只保留该循环的粒子
- **器官索引 + 视角预设**：左侧 11 个器官可点可悬停高亮；胸腔 / 腹腔 / 头部 / 全身视角一键切换，点器官自动框选构图
- **标签避让**：12 个 3D 标签每两帧做一次屏幕空间避让，远景下自动收起次要标签（脾、胰、膀胱）
- **透视调节**：0~60% 逐档调节皮肤厚度，看得清器官也看得见人体轮廓
- **神经语音讲解**：21 段晓晓语音（11 个器官 + 7 类血管 + 3 个循环），预生成在 `src/audio/circulation/`

**操作方式：**

| 操作 | 说明 |
| ---- | ---- |
| 点击器官 / 名称标签 / 左侧索引 | 查看科普卡片并朗读 |
| 拖拽 / 滚轮 | 旋转 / 缩放 |
| 全部 / 体循环 / 肺循环 | 只看某一条循环通路 |
| 胸腔 / 腹腔 / 头部 | 切换视角预设 |
| 👁 透视 | 调节人体透明度 |
| ⏸ / 🔊 | 暂停动画 / 开关语音 |

**技术要点：**

- 自写两个参数化建模器：`sweep()`（沿曲线扫掠，半径可逐点变化、可压扁成椭圆、端头收圆）与 `loftRings()`（分层放样，截面可左右/前后不同半径并带偏移），器官轮廓都由解剖数据逐段定义，而不是靠变形球拼
- 人体为程序化生成（头/颈/胸/腰/髋/四肢），不再依赖外部 GLB；用 BackSide 加法外壳做轮廓光
- 血管用 Additive 流动 Shader（沿管长推进的柔和脉冲），粒子用 `InstancedMesh` 逐实例上色
- 器官材质 `DoubleSide` + 描边壳，叠在一起时仍能分清边界

### 🌧️ 天气系统 · 水循环（src/weather/weather.html）

一座有雪山、森林、湖泊与河流的岛，把水循环的七个环节做成看得见的实体。

**核心功能：**

- **程序化地形**：高度场（岛屿轮廓 + 三座山峰 + 山脊 + 岩石棱角 + 噪声）生成雪山、林坡、湖盆、河谷与沙滩；顶点色按海拔与坡度上色（深海 → 浅滩 → 沙滩 → 草地 → 岩石 → 积雪），雪线以上缓坡积雪、陡壁露岩
- **七个环节实体化**：
  - 蒸发 —— 海面升起的金色水汽柱（粒子 shader，随高度淡入淡出）
  - 蒸腾 —— 森林上方的绿色水汽，与蒸发用不同色温和上升速率
  - 凝结 —— 每朵云由 6~7 个噪声球拼成三维体积云，分「晴云」「雨云」两组
  - 降水 —— 实例化雨幕（最多 900 条），每条雨丝按落点地形高度重生，不穿模
  - 径流 —— 沿河谷下切的水带，带沿程推进的流动条纹，从雪山穿过湖泊流向大海
  - 下渗 —— 钻入地表的紫色粒子 + 一条贴地地下水流线
  - 汇流 —— 江河回到海洋，闭合循环
- **11 个可点对象 + 11 个 3D 标签**：太阳、雪山、森林、湖泊、河流、云、海洋、蒸发、蒸腾、降水、下渗；标签做了逐帧投影与避让，重叠时自动下移
- **分段讲解**：全景 / 海洋段 / 大气段 / 陆地段，切换时镜头飞向对应区域，只高亮本段元素，其余压暗
- **四档天气**：晴朗 / 多云 / 降雨 / 暴雨，云量、云色、雨量、日照、雾浓度、天空色、水面色调七项参数平滑过渡
- **每个条目 4 条数据 + 2 条描述 + 2 条冷知识**：全球年蒸发 50 万 km³、云滴直径 0.02 mm、雨滴最大 6 mm、地下水 2340 万 km³ …
- **神经语音讲解**：17 段（7 环节 + 6 实体 + 4 分段），edge-tts 预生成在 `src/audio/weather/`（约 2 MB），缺失时自动回退浏览器语音

### 🏯 江南园林 · 缩千里于咫尺（src/garden/garden.html）

一座按造园手法搭起来的微缩园林：粉墙黛瓦围出一亩三分地，中间一池水，四周亭台楼榭。

**核心功能：**

- **借景**：园外远处立一座塔，半隐在雾里——这就是《园冶》说的"园虽别内外，得景则无拘远近"

- **五组视角**：全园 / 亭中（从亭内往外看）/ 水榭 / 洞口（框景机位）/ 俯瞰
- **十四个可点对象 + 15 个 3D 标签**，标签逐帧投影避让
- **每条目 4 条数据 + 2 条描述 + 2 条冷知识**：狮子林 9 条山路 21 个洞、宋徽宗花石纲、留园一条廊几十种漏窗不重样、荷叶效应 …
- **神经语音讲解**：16 段（10 景 + 4 植物 + 2 手法），edge-tts 预生成在 `src/audio/garden/`（约 2 MB）

### 🏜️ 悬泉置 · 丝路驿站（src/xuanquan/xuanquan.html）

敦煌以东的戈壁滩上，一座 50 × 50 米的汉代坞院。数据据悬泉置遗址考古资料整理。

**核心功能：**

- **坞院复原**：夯土墙（横夯层 + 模板缝的 canvas 纹理）、**东开**的院门与木构门楼、墙顶女墙、院内地坪

### 🦖 恐龙 · 地质年代漫游（src/dinosaur/dinosaur.html）

真实骨骼动画恐龙模型 + 时间机器穿梭地质年代。

**核心功能：**

- **真实 3D 恐龙**：使用 CC0 授权的 Gobkit 恐龙模型（GLB），带完整骨骼与 idle / walk / attack / dead 四段动画
- **地质年代漫游**：三叠纪（真双型齿翼龙、腔骨龙）→ 侏罗纪（剑龙一家、翼手龙）→ 白垩纪（霸王龙、三角龙、甲龙、食肉牛龙）
- **8 种史前生物档案**：每种 6 条数据（体长 / 体重 / 年代 / 食性 …）+ 4 条描述 + 2~3 条「冷知识」，全部按适合孩子听的口语写
- **神经语音讲解**：进入每一纪自动讲这一纪的故事，点恐龙讲这只恐龙；`🎧 再讲一遍` 可以重听。音频由 edge-tts 预生成在 `src/audio/dinosaur/`（12 段，约 2 MB），缺失时自动回退浏览器语音
- **小行星撞击事件**：白垩纪点击「小行星撞击」，火球坠落、天空被尘埃遮蔽，所有恐龙应声倒下（dead 动画），并播放灭绝旁白
- **环境变迁**：渐变天空穹顶、噪声起伏地形、蕨类 / 针叶林 / 阔叶林随年代更替，实时软阴影
- **交互与讲解**：点恐龙身体或点名字标签都能选中，镜头平滑聚焦、恐龙做一次攻击动作
- **时间漫游**：自动依次播放三个纪，每纪停留 26 秒，刚好听完讲解

> 模型来源：Gobkit Free Dinosaur Pack（CC0 1.0，可商用、无需署名），存放于 `src/dinosaur/models/`。

### 👶 人口 · 出生人口（src/birth/birth.html）

中国大陆 1985-2025 年每年出生人口三维柱状图 + 出生率折线。

**核心功能：**

- **双色映射**：柱高与颜色同时编码出生人口（低值冷蓝 → 高值暖琥珀）
- **出生率折线**：粉色管状折线叠加在柱列前方，带数据点圆球
- **坐标网格**：横向网格线与万人刻度、年份标签、峰值（1987）/低谷（2025）标注
- **入场动画**：柱子从左到右依次长高（easeOutCubic）
- **交互查看**：悬停柱或折线数据点，显示该年人口与出生率
- **语音讲解**：悬停年份后朗读数据（可开关）

## 运行方式

所有示例均为自包含的纯静态 HTML 单文件，无需构建工具、无需本地服务器。

```bash
# 方式一：直接双击打开首页（file:// 即可运行）
open index.html

# 方式二：也可通过本地静态服务器访问
python3 -m http.server 8000
# 然后访问 http://localhost:8000/
```

> 注意：页面通过 CDN 加载 Three.js，首次运行需要网络连接。

## 技术栈

- [Three.js](https://threejs.org/) — 3D 渲染引擎（importmap 从 CDN 加载）
- [edge-tts](https://github.com/rany2/edge-tts) — 离线批量生成神经网络语音讲解（构建期使用，运行期只播 mp3）
- Web Speech API — 语音包缺失时的兜底朗读
- 原生 HTML / CSS / JavaScript（ES Module，单文件内联）
